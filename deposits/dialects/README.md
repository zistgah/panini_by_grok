# deposits/dialects

Three layers. Keep them uncollapsed.

| file | layer |
|---|---|
| phonetic.tsv | script / sound (name-projection or retrieved map) |
| words.tsv | word choice (same columns as language TSV + dialect tag) |
| syntax.tsv | shaili extras |

A dialect is not a new programming language. It is a row-set on one of these axes.
