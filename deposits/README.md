Handoff tray for **human and AI** collaborators. Do not edit the live tree here.

## How to pick up work

1. Read `docs/CONTRACT.md` and `docs/CONTEXT.md` first.
2. Take **one** open item from `TASKS.md` (status `open`).
3. Put your result in `deposits/inbox/<task-id>/` with:
   - `NOTE.md` — what you did, what you did **not** invent, tests run
   - the files
4. Do not invent keyword maps, cuneiform languages, or `#define` localization.
5. A later turn processes inbox → the proper path (frontends, langs, tests).

Frozen notebook chrome: `docs/nb.frozen.html`. Do not restyle it.
