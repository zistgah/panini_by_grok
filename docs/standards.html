Official standards

These are the suites that count as “standards.” This tree maps them. It does not mark them PASS.

  • C — ISO/IEC 9899, gcc torture, c-testsuite
  • C++ — ISO/IEC 14882, libc++ / libstdc++
  • Python — CPython Lib/test, PEPs
  • Fortran — ISO/IEC 1539, gfortran torture
  • Julia — Julia test/
  • Rust — rustc ui
  • Go — Go spec + go test
  • TypeScript / JS — TS tests + ECMA-262 Test262
  • Zig, Java (JLS), Kotlin, Scala, C# (ECMA-334), F#, Swift
  • Ruby spec, PHPT, perl harness, R Language Definition, Octave test/
  • Haskell 2010, OCaml, OTP, Elixir, Lua
  • COBOL ISO 1989, Ada ACATS, Pascal ISO 7185, BASIC ECMA-116
  • R7RS, Prolog ISO 13211, SQL ISO 9075, WASM spec, WGSL
  • PANINI — tests/panini/ (owned)
