What Hindawi actually is

Not Gurmukhi→Devanagari. Not if→यदि. A reversible pipeline so a C program written in a vernacular script still compiles with gcc and still debugs in that script.

The retrieved Guru compiler

cat $1 | acii2uni | iconv | h2c > temp.c
gcc temp.c
  1. unicode.h — Devanagari → ACII (8-bit phonetic layer).
  2. acii2rmn.c — stack: consonants carry implicit a; matras pop it. मुख्य → mukhya, not a letter-wise concat.
  3. h2c.lex — Romenagri tokens → C. mukhya→main, ma_likhoa→printf.
  4. Identifiers stay Romenagri (अ→_a, क→ka) so they are legal C and reverse.
  5. Strings stay UTF-8 vernacular. APCISR paints ACII as Indic in true text mode.

#समावेश becomes #samaawaeesha (schwa) so it does not hit #samaawesha in h2c; मानकपन.स does become stdio.h. That gap is reported, not patched with an invented alias.
