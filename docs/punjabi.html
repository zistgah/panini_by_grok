ਪੰਜਾਬੀ — Gurmukhi port of Hindawi

Same architecture as Shaili Guru. Not a new keyword invention. Script layer uses Unicode name-projection; keywords are the retrieved Punjabi TSV.

  1. Gurmukhi → Devanagari — replace GURMUKHI with DEVANAGARI in the Unicode character name (the method the Romenagri *_to_deva.tsv headers declare). 67 letters/signs map; 13 Gurmukhi-only names stay unmapped (addak, tippi, EE/OO naming).
  2. Gurmukhi → Romenagri → C — retrieved/romenagri/langs/punjabi_c.tsv (native, romenagri, c). Same three columns as Hindi’s h2c path, Punjabi rows.

ਜੇ is not Hindi जे-as-if via h2c.lex. Punjabi ਜੇ → jee → if from the Punjabi table.
