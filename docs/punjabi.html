Punjabi is another Shaili, not Hindi in Gurmukhi

Gurmukhi→Devanagari is the ILM script hub. Computational localization is ACII → Romenagri → Punjabi lex / #define, matching gurmukhi_demo.c.

/* retrieved/romenagri/demos/gurmukhi_demo.c */
#define je if
#define jada_taka while
#define chhapo printf
int gi_n_tee = 0;
jada_taka (gi_n_tee < 5) {
  je (gi_n_tee % 2 == 0) chhapo("%d sam\n", gi_n_tee);
  gi_n_tee++;
}
  • Native names in comments: ਜੇ / ਜਦੋਂ ਤੱਕ / ਛਾਪੋ
  • Source gcc sees: Romenagri identifiers, C-legal
  • Shaili here is #define (tiny) — Hindi Guru uses h2c.lex (321 rules)
  • Punjabi keywords: retrieved langs/punjabi_c.tsv (ਵਾਪਸ / vaapasa / return) — not h2c’s Hindi waapasa

Unicode name-projection cannot map GURMUKHI VOWEL SIGN EE (13 such names). Those stay unmapped. The retrieved demo does not invent them; it writes je directly.
