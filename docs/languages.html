Host language

PANINI (.pni) — self-host subset verified A=B=C on the compiler core.

Frontends written in PANINI (subsets)

  • Python — print, def, return, lists, tensor/matmul
  • C — functions, return, printf, arithmetic
  • C++ — subset → WASM on flow.html; native C++11 via g++/cmake is how llama.cpp builds. Not collapsed.
  • Fortran — PROGRAM / PRINT
  • Rust — fn, let, println
  • TypeScript — function, console.log
  • Go — func, fmt.Println
  • Zig — pub fn, debug.print

Not present

Julia frontend is listed on the standards map and is not implemented.

Classifications

  • VERIFIED — PANINI self-host subset
  • VERIFIED_SUBSET — foreign frontend tests in tests/lang_cases
  • PARTIAL — PyTorch-shaped ops, WebGPU, LSP, debugger
  • NOT_RUN — official upstream suites

On the site they lower to host C, then C → WASM. Python uses the AST. Braced languages use a numeric subset transducer (to_c.pni). Proven: compute(5)=25 for Python, Rust, Go, TypeScript, Zig, Lua, C++.
