Build (your machine)

python3 -m pip install cmake   # if needed
git clone --depth 1 https://github.com/ggml-org/llama.cpp.git
cd llama.cpp
cmake -B build -DCMAKE_BUILD_TYPE=Release \
  -DGGML_NATIVE=OFF -DLLAMA_BUILD_TESTS=OFF -DLLAMA_CURL=OFF
cmake --build build --config Release --target llama-cli
./build/bin/llama-cli --version
./build/bin/llama-cli -m model.gguf -p "Once upon a time" -n 16 -st --no-jinja

Script in the tree: tools/llm/build.sh /path/to/llama.cpp

Optional GPU

  • NVIDIA: CUDA Toolkit, -DGGML_CUDA=ON
  • Apple: Metal via Xcode (built-in)
  • AMD: ROCm/hipBLAS, -DGGML_HIP=ON
  • Vulkan SDK, -DGGML_VULKAN=ON

GitHub Pages does not run this binary. The C++ frontend on the site is the subset path. Native llama.cpp is the host toolchain.
