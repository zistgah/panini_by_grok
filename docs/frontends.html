Driven by data/frontends.json. The workbench chrome is frozen. Add a frontend there.

Frontends

Every frontend on the workbench. ISO GREEN is STANDARD GREEN whose issuing body is ISO/IEC, ANSI/INCITS, IEEE, ECMA (ISO-adopted), or NIST. STANDARD GREEN is issuing-body spec ∧ that body's executable suite skip=0. Homemade suites are CORE GREEN only. Named GAPs stay named.
