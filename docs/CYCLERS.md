Cyclers are the AI harness. They are not the language.

Presentation (child-simple): a person with no Git, no GitHub, no API key
walks a prompted path on the website or PWA.

Substrate (highest end): the same cycler is a governed workflow over
PANINI IR, POSIX, OCI environments, and later Qiskit / other scientific
runtimes.

```
person  →  cycler script (FAKIR / CHARBAGH / GENIE / …)
                 │
                 ├─ retrieve, do not invent
                 ├─ prompt steps when no model key is present
                 └─ elevate to GENIE when a sovereign asks
                          │
                          ▼
                 PANINI program + provenance
                          │
                 frontends-in-PANINI  ∧  standard environments
```

This file records the requirement. Full Cognitive Workbench behavior
needs the architecture pack the architect will supply. It is not guessed.
